## [0.1.0]

### Добавлено

- Апплет системного трея (StatusNotifierItem, `ksni`) для labwc / LXQt на
  Wayland: инхибитор idle включён (чашка) или сон разрешён (луна).
- Инхибитор держится одновременно в wayland (`zwp_idle_inhibitor_v1` на
  собственной поверхности с прозрачным буфером 1×1 — так его видят wlroots) и
  в logind (`Inhibit("idle", …, "block")`, виден в `systemd-inhibit --list`).
- Автовключение по медиа (MPRIS через `playerctl`) — `--auto`.
- Ручное выключение в режиме `--auto` приостанавливает авто-включение, пока
  медиа не остановится; после паузы или конца воспроизведения подавление
  снимается, и при следующем запуске медиа инхибитор поднимается сам.
- Цвет иконки по активной теме LXQt (qss `Plugin > QToolButton` →
  `LXQtPanel` → `#BackgroundWidget` → палитра `window_text_color`), иначе по
  контрасту к фону панели (LXQt, Waybar, swaybar).
- Меню трея: статус, переключение, выход. `--dump-icons` для проверки цвета.
- Конфигурационный файл `config.toml`: системный
  `/etc/xdg/tray-idle-inhibitor/config.toml` (первый существующий из
  `XDG_CONFIG_DIRS`) и пользовательский `~/.config/tray-idle-inhibitor/config.toml`
  (`XDG_CONFIG_HOME`). Пользовательский файл переопределяет только указанные в
  нём ключи; секция `[color]` сливается по ключам. Неизвестный ключ или неверный
  тип отбрасывает файл целиком с сообщением в stderr.
- Ключи `auto` (эквивалент `--auto`), `start_on` (эквивалент `--start-on`),
  `interval_secs` (эквивалент `-i`). Флаги командной строки сильнее конфига.
- Секция `[color]`: `mode = "theme" | "auto" | "fixed"`, `theme` — имя темы LXQt
  для цвета вместо активной из `lxqt.conf`, `fg` — цвет для `fixed`.
- Пример конфигурации `config.toml` в репозитории.
- Запрет второго экземпляра: `flock` на
  `$XDG_RUNTIME_DIR/tray-idle-inhibitor.lock` (резерв —
  `/tmp/tray-idle-inhibitor-<uid>.lock`). При занятости в stderr пишется
  `уже запущен (pid N)`, выход с кодом 0. Блокировка снимается ядром при
  завершении процесса, файл не мешает следующему запуску.
- Флаг `--version` / `-V`: печатает имя и версию из `Cargo.toml`.
- Однократное предупреждение в stderr, если `playerctl` не установлен или не
  запускается: раньше `--auto` молча не срабатывал.
- `tray-idle-inhibitor.desktop` для меню приложений и автозапуска.
- CI (GitHub Actions): `cargo fmt --check`, `cargo clippy -D warnings`,
  `cargo test`, `cargo build --release`.
- README: разделы «Скриншот», «Требования», «Сборка», «Установка», «Запуск»
  и «Разработано с помощью ИИ»; иконки перенесены в `docs/`.

### Исправлено

- `start_on` больше не игнорируется вместе с `auto`: раньше при
  `--start-on --auto` инхибитор при старте не поднимался (`manual_start =
  opts.start_on && !opts.auto`). Теперь оба флага совместимы.
- Защита от дублей не путает «занято» и «файл недоступен»: ошибка открытия
  lock-файла (`XDG_RUNTIME_DIR` не существует, каталог не пишется) больше не
  выглядит как работающий экземпляр — печатается причина, запуск продолжается.
- Резервный путь блокировки в `/tmp` использует один и тот же файл с uid и для
  `flock`, и для чтения pid (раньше имя с uid строилось только для чтения).
- Поиск системного конфига ограничен `XDG_CONFIG_DIRS` (`/etc/xdg`), без
  нестандартного `/usr/local/etc/xdg`; пользовательский путь собирается через
  `Path::join`, а не строкой.

### Изменено

- `theme::icon_color` принимает режим цвета и цвет `fixed`; тема для расчёта
  цвета может быть задана конфигом (`theme::set_theme`) вместо активной темы
  панели.
- `--help` показывает пути конфига и перечень ключей.
- Зависимости: `serde` (derive) и `toml` (фичи `parse`, `serde`).
- `cargo test` — 16 тестов (добавлены проверки слияния конфига и значений,
  блокировки единственного экземпляра, правила «ручное сильнее auto»).

### Проверено

- Тема `system`: `--dump-icons` даёт `#181818` на фоне `#efefef`, контраст
  15.4:1. В qss темы нет правил цвета для плагинов, палитры
  `lxqt/palettes/system` в системе нет, поэтому работает резервный путь
  «фон панели → чёрный/белый».
- Приоритет файлов: системный `theme = "system"` + пользовательский
  `mode = "fixed", fg = "#ff0000"` дают `#ff0000`; пользовательский файл
  перекрывает только свои ключи.
- Без `XDG_RUNTIME_DIR` блокировка ложится на `/tmp/tray-idle-inhibitor-<uid>.lock`,
  дубль отклоняется; при `XDG_RUNTIME_DIR=/nonexistent` печатается причина и
  программа работает без защиты.
- Дубликат: второй запуск при работающем первом печатает
  `уже запущен (pid 143328)` и выходит с кодом 0; после остановки первого
  программа снова стартует.
- Битый TOML не мешает запуску: в stderr причина, работа продолжается на
  системном файле и значениях по умолчанию.
- `--version` печатает `tray-idle-inhibitor 0.1.0` и выходит с кодом 0.
- `cargo fmt --check` и `cargo clippy --all-targets -- -D warnings` — чисто.
